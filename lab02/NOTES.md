Cегодня выполняем вторую лабораторную работу, работаем в Git
рабочая папка - это та папка на компьютере, в которой идет работа над файлами
индекс - это промежуточная область, в которую добавляются файлы для включения в следующий коммит
коммит - это фиксация изменений с пояснением
различия Git и GitHud:
Git - это программа на компьютере, среда, в которой создается код.
GitHub - это удаленный сервис для размещения проектов, доступ для участников и  выполнения совместной работы с другими разработчиками, обсуждение изменений.
Использованные комманды:
git status - показывает, в каком состоянии на данный момент находится репозиторий
git diff - показывает те изменения, которые еще не были сохранены
git diff --staged - показывает уже измененные изменения
Ветки:
Ветки позволяют работать с определенного коммита, не затрагивая основную ветку, что позволяет разработчикам одновременно работать над репозиторием, избегая несостыковок
при новом коммите создается коммит только в созданной ветке, а не основной
слияние дает "присоединение" веток к основной
